## Request management (zps-pareto plugin)
- Every request (email, chat, call) becomes a GitHub issue before any work: use `/zps-pareto:intake`.
- Scoring and priority rules: `.claude/pareto.md`, or the portfolio hub it names. Follow them.
- Prioritize the backlog with `/zps-pareto:triage`; ask `/zps-pareto:next` for what to work on now.
- Reference the issue in every commit/PR (`Refs #123`, or `owner/repo#123` across repositories; never `Fixes` or `Closes` before the acceptance criteria are verified).
